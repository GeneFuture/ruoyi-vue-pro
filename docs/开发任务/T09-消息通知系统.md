### 1.2 创建通知模板

在管理后台 → 消息管理 → 站内信模板 中创建：

| 模板编码 | 模板名称 | 内容模板 |
|---------|---------|---------|
| `MARITIME_ENROLL_SUCCESS` | 报名成功通知 | 您已成功报名【{sessionName}】班期，开班日期 {startDate}，请按时参加。 |
| `MARITIME_DEPOSIT_PAID` | 定金支付成功 | 【{sessionName}】定金 {amount} 元支付成功！您已获得推荐权，快去分享给好友吧～ |
| `MARITIME_GROUPON_SUCCESS` | 拼团成功 | 恭喜！您参加的【{sessionName}】拼团已成功，共 {count} 人成团。 |
| `MARITIME_GROUPON_DEGRADED` | 拼团降级通知 | 您参加的拼团已超时，报名将按原价继续。如有疑问请联系客服。 |
| `MARITIME_BALANCE_REMINDER` | 尾款催缴 | 您报名的【{sessionName}】将于 {startDate} 开班，请于 {deadline} 前支付尾款 {amount} 元。 |
| `MARITIME_REFERRAL_SUCCESS` | 推荐成功 | 您推荐的好友已完成报名！佣金 {amount} 元正在审核中，审核通过后 T+1 发放。 |
| `MARITIME_COMMISSION_PAID` | 佣金到账 | 恭喜！{amount} 元推荐佣金已转入您的微信零钱。 |

  // 接收前端上报的订阅结果
  public CommonResult<Boolean> saveSubscribeStatus(
      @RequestBody Map<String, String> subscribeResults) {
      // key: templateId, value: "accept" / "reject"
      subscribeResults.forEach((templateId, status) -> {
          memberSubscribeMapper.upsert(new MemberSubscribeDO()
              .setMemberId(currentMemberId)
              .setTemplateId(templateId)
              .setIsSubscribe("accept".equals(status)));
      });

  }

### 2.3 WxSubscribeMsgService 实现

**文件**：`WxSubscribeMsgServiceImpl.java`

```java
@Service
public class WxSubscribeMsgServiceImpl {
    
    // 模板ID配置（从 application.yaml 读取）
    @Value("${maritime.notify.wx.template.deposit-paid}")
    private String depositPaidTemplateId;
    
    @Value("${maritime.notify.wx.template.commission-paid}")
    private String commissionPaidTemplateId;
    
    // ... 其他模板ID
    
    public void sendDepositPaid(String openId, String sessionName, BigDecimal amount) {
        // 检查用户是否订阅了此模板
        if (!isSubscribed(getOpenIdMemberId(openId), depositPaidTemplateId)) {
            log.debug("[wx-subscribe] 用户未订阅，跳过发送: openId={}", openId);
            return;
        }
        
        send(openId, depositPaidTemplateId, Map.of(
            "thing1", Map.of("value", sessionName),
            "amount2", Map.of("value", amount + "元"),
            "time3", Map.of("value", LocalDateTime.now().format(DATE_FORMATTER))
        ), "/pages/my/enrollments");
    }
    
    private void send(String openId, String templateId, Map<String, Object> data, String page) {
        try {
            WxMaSubscribeMessage message = new WxMaSubscribeMessage();
            message.setToUser(openId);
            message.setTemplateId(templateId);
            message.setPage(page);
            message.setData(data.entrySet().stream()
                .map(e -> new WxMaSubscribeMessage.MsgData(e.getKey(), 
                    (String)((Map)e.getValue()).get("value")))
                .collect(toList()));
            
            wxMaService.getMsgService().sendSubscribeMsg(message);
        } catch (WxErrorException e) {
            log.warn("[wx-subscribe] 发送失败: openId={}, templateId={}, error={}", 
                openId, templateId, e.getMessage());
            // 订阅消息发送失败不影响主流程
        }
    }
}
```

@Component

public class MaritimeNotifyEventListener {
    
    @Async  // 异步处理，不阻塞主流程

    public void onEnrollmentCreated(EnrollmentCreatedEvent event) {
        EnrollmentDO enrollment = enrollmentMapper.selectById(event.getEnrollmentId());
