### 1.2 请求参数 VO

```java
public class AppEnrollmentCreateReqVO {
    @Schema(description = "班期ID", required = true)
    @NotNull
    private Long sessionId;
    
    @Schema(description = "真实姓名", required = true)
    @NotBlank
    @Size(max = 50)
    private String realName;
    
    @Schema(description = "身份证号", required = true)
    @NotBlank
    @IdCard  // 自定义校验注解或正则
    private String idCard;
    
    @Schema(description = "手机号", required = true)
    @NotBlank
    @Mobile
    private String phone;
    
    @Schema(description = "推荐码（可选，来自分享链接）")
    private String referralCode;
    
    @Schema(description = "是否参与拼团（true=新建拼团，false=单独报名）")
    private Boolean joinGroupon = false;
    
    @Schema(description = "加入的拼团邀请码（joinGroupon=true时，有值=加入已有拼团，无值=新建拼团）")
    private String grouponInviteCode;
}
```

### 1.3 Service 逻辑

**文件**：`EnrollmentServiceImpl.java` → `createEnrollment()`

- [ ] **Step 1：前置校验**
  ```java
  // 1.1 班期存在且状态为 OPEN
  CourseSessionDO session = sessionService.getSession(createReqVO.getSessionId());
  if (session == null || !SessionStatusEnum.OPEN.getStatus().equals(session.getSessionStatus())) {
      throw exception(SESSION_NOT_OPEN);
  }
  
  // 1.2 班期未满员
  SessionFeeConfigDO feeConfig = feeConfigService.getBySessionId(session.getId());
  if (session.getEnrolledCount() >= session.getMaxStudents()) {
      throw exception(SESSION_FULL);
  }
  
  // 1.3 同一身份证未重复报名同班期（加密后比对）
  String encryptedIdCard = AesUtils.encrypt(createReqVO.getIdCard());
  EnrollmentDO existingEnrollment = enrollmentMapper.selectByIdCardAndSession(
      encryptedIdCard, createReqVO.getSessionId());
  if (existingEnrollment != null) {
      throw exception(ENROLLMENT_DUPLICATE);
  }
  ```

- [ ] **Step 2：创建报名记录**
  ```java
  EnrollmentDO enrollment = EnrollmentConvert.INSTANCE.convert(createReqVO);
  enrollment.setMemberId(LoginUserContextHolder.getUserId());
  enrollment.setIdCard(encryptedIdCard);  // 加密存储
  enrollment.setEnrollmentStatus(EnrollmentStatusEnum.PENDING_DEPOSIT.getStatus());
  enrollment.setReferralRightGranted(false);
  enrollmentMapper.insert(enrollment);
  ```

- [ ] **Step 3：创建定金订单**
  ```java
  EnrollmentOrderDO depositOrder = new EnrollmentOrderDO();
  depositOrder.setEnrollmentId(enrollment.getId());
  depositOrder.setOrderNo(generateOrderNo());  // 时间戳 + 随机数
  depositOrder.setOrderType(OrderTypeEnum.DEPOSIT.getType());
  // 判断是否有拼团优惠
  BigDecimal depositAmount = feeConfig.getDepositAmount();
  if (isGrouponSuccessAtJoin) {
      depositAmount = depositAmount.subtract(feeConfig.getGrouponDiscountAmount());
  }
  depositOrder.setAmount(depositAmount);
  depositOrder.setOrderStatus(OrderStatusEnum.PENDING.getStatus());
  depositOrder.setExpireTime(LocalDateTime.now().plusMinutes(30));  // 30分钟过期
  enrollmentOrderMapper.insert(depositOrder);
  ```

- [ ] **Step 4：更新班期报名人数**
  ```java
  // CAS 更新，防并发超卖
  int updated = sessionMapper.incrementEnrolledCount(session.getId(), session.getMaxStudents());
  if (updated == 0) {
      throw exception(SESSION_FULL);  // 并发时被抢满
  }
  ```

- [ ] **Step 5：返回结果**
  ```java
  return new AppEnrollmentCreateRespVO()
      .setEnrollmentId(enrollment.getId())
      .setOrderId(depositOrder.getId())
      .setOrderNo(depositOrder.getOrderNo())
      .setDepositAmount(depositOrder.getAmount())
      .setExpireTime(depositOrder.getExpireTime());
  ```

### 1.4 防超卖 SQL

在 `CourseSessionMapper` 中：
```sql
UPDATE maritime_course_session
SET enrolled_count = enrolled_count + 1
WHERE id = #{id}
  AND enrolled_count < max_students
  AND deleted = 0
```

## 3. 身份证加密

- [ ] 确认使用 AES-256-GCM 加密存储身份证
  - 密钥存放在配置文件中（生产环境用 KMS 或 Vault）
  - 日志中不打印身份证号（在 AOP 日志脱敏）
- [ ] 查询时加密后比对（不解密比较原文）
- [ ] 管理员查看时：仅显示脱敏版本（前4后4，中间\*\*\*\*\*\*\*\*\*\*）

---

## 4. 报名取消（学员主动）

- [ ] `POST /app-api/maritime/enrollment/cancel`
  - 只允许取消 `PENDING_DEPOSIT` 状态的报名（尚未支付）
  - 取消后：`enrollment.status → CANCELLED`
  - 减少班期的 `enrolled_count`（归还名额）
  - 关闭对应定金订单

## 8. 测试要点

- [ ] 同一身份证不能重复报名同班期
- [ ] 班期满员时（enrolled_count >= max_students），报名返回失败
- [ ] 并发报名时不会超出 max_students（CAS 防超卖）
- [ ] 推荐码传入时正确记录 `referral_code_used`（推荐关系在支付后建立，此处仅记录）
- [ ] 未登录用户调用创建报名接口，返回 401
- [ ] 取消报名后 `enrolled_count` 正确减少
