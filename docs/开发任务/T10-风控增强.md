## 1. Rule 3：批量推荐检测

### 1.1 规则定义

```
检测条件：
  24 小时内，同一推荐人推荐成功（推荐关系建立）超过 N 人
  N = 10（可通过系统参数配置，但不暴露给前端用户）
  
触发后处理：
  - 超过阈值的新推荐进入"待人工审核"状态
  - 推荐人账号自动设置 is_referral_banned = true（临时）
  - 通知管理员
  - 管理员审核：确认正常 → 解除禁推，已拦截推荐补录
  - 管理员审核：确认异常 → 保持禁推，已触发佣金撤销
```

### 1.2 检测实现

**文件**：`RiskCheckServiceImpl.java` 中增加 Rule 3：

```java
// Rule 3: 批量推荐检测（在 establishRelationIfPresent 时调用）
private boolean checkBatchReferralLimit(Long referrerId) {
    // 统计 24h 内该推荐人的有效推荐数
    LocalDateTime since = LocalDateTime.now().minusHours(24);
    int count = referralRelationMapper.countActiveByReferrerSince(referrerId, since);
    
    // 从系统参数表读取阈值（SysConfigServiceImpl）
    int limit = Integer.parseInt(sysConfigService.getConfigValueByKey(
        "maritime.risk.batch_referral_limit", "10"));
    
    return count >= limit;
}
```

在 `ReferralServiceImpl.establishRelationIfPresent()` 中加入：

```java
// Rule 3 检查
if (riskCheckService.checkBatchReferralLimit(referrer.getId())) {
    // 超出阈值
    log.warn("[risk] 批量推荐告警: referrerId={}", referrer.getId());
    
    // 临时禁推
    memberUserMapper.updateReferralBanned(referrer.getId(), true);
    
    // 记录风控事件
    riskEventMapper.insert(new RiskEventDO()
        .setType(RiskEventTypeEnum.BATCH_REFERRAL)
        .setMemberId(referrer.getId())
        .setDetail("24h内推荐超过限制"));
    
    // 通知管理员
    alarmService.sendAlert("批量推荐告警，推荐人ID=" + referrer.getId() + 
        "，24h内推荐超过" + limit + "人");
    
    // 当次推荐拒绝
    return RiskCheckResult.fail("推荐频率超过限制，已暂停推荐权限");
}
```

## 2. 拼团防刷

### 2.1 规则

```
检测：同一微信账号（openid）在 24h 内创建超过 3 个拼团
处理：超出阈值则拒绝创建新拼团，提示"操作频繁"
实现：Redis 限流（不记数据库）
```

### 2.2 实现

在 `GrouponServiceImpl.createGrouponRecord()` 中加入：

```java
private void checkGrouponCreateLimit(Long memberId) {
    String key = "groupon:create:limit:" + memberId;
    Long count = redisTemplate.opsForValue().increment(key);
    
    if (count == 1) {
        // 首次，设置 24h 过期
        redisTemplate.expire(key, 24, TimeUnit.HOURS);
    }
    
    int limit = 3;  // 硬编码限制
    if (count > limit) {
        throw exception(GROUPON_CREATE_FREQ_LIMIT);
    }
}
```
