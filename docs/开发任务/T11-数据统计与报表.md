### 1.2 数据指标

**文件**：`AdminDashboardRespVO.java`

```java
public class AdminDashboardRespVO {
    // ── 今日数据 ──
    private Integer todayNewEnrollments;       // 今日新报名数
    private BigDecimal todayDepositAmount;      // 今日收款（定金）
    private BigDecimal todayBalanceAmount;      // 今日收款（尾款）
    
    // ── 本月数据 ──
    private Integer monthNewEnrollments;        // 本月新报名数
    private BigDecimal monthTotalRevenue;       // 本月总收款
    private Integer monthSuccessGroupons;       // 本月成团数
    
    // ── 班期招生进度（当前开放报名的班期）──
    private List<SessionProgressVO> openSessionProgress;
    
    // ── 趋势图（近7天/近30天报名量）──
    private List<DailyStatVO> enrollmentTrend;
    
    // ── 快速待办 ──
    private Integer pendingRefundApplies;       // 待处理退费申请数
}

public class SessionProgressVO {
    private String sessionCode;
    private String courseName;
    private LocalDate startDate;
    private Integer maxStudents;
    private Integer enrolledCount;
    private Integer completedCount;      // 已完成（尾款全付）
    private BigDecimal confirmedRevenue; // 已确认收款
}
```

### 1.3 Service 实现

```java
public AdminDashboardRespVO getDashboard(LocalDate date) {
    LocalDate today = (date != null) ? date : LocalDate.now();
    LocalDate monthStart = today.withDayOfMonth(1);
    
    return new AdminDashboardRespVO()
        // 今日报名数（当天 00:00 到现在）
        .setTodayNewEnrollments(enrollmentMapper.countByCreateTimeBetween(
            today.atStartOfDay(), today.atTime(23, 59, 59)))
        // 今日收款
        .setTodayDepositAmount(enrollmentOrderMapper.sumPaidAmountByType(
            today.atStartOfDay(), today.atTime(23, 59, 59), OrderTypeEnum.DEPOSIT))
        // ... 其他统计（均为简单 COUNT/SUM 聚合查询）
        ;
}
```

> **性能提示**：Dashboard 查询较多，建议加 Redis 缓存（5分钟 TTL），避免每次访问都查数据库。

### 2.2 导出字段

使用 ruoyi-vue-pro 内置的 EasyExcel 集成：

```java
@ExcelProperty("序号")        Integer index;
@ExcelProperty("姓名")        String realName;
@ExcelProperty("身份证号")    String idCard;      // 脱敏：前4后4，中间*
@ExcelProperty("手机号")      String phone;       // 脱敏：前3后4，中间****
@ExcelProperty("班期编号")    String sessionCode;
@ExcelProperty("报名时间")    String createTime;
@ExcelProperty("报名状态")    String status;      // 中文显示：待付定金/已完成/...
@ExcelProperty("定金金额")    BigDecimal depositAmount;
@ExcelProperty("尾款金额")    BigDecimal balanceAmount;
```

### 2.3 权限控制

- 导出包含身份证（脱敏）：需要 `maritime:enrollment:export` 权限
- 导出完整身份证：需要额外的 `maritime:enrollment:export-full` 权限（高权限）
