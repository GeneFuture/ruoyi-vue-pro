### 1.9 启动中间件（Docker Compose）

在项目根目录创建 `docker-compose.yml`，统一管理 MySQL 和 Redis，并挂载数据卷防止数据丢失：

```yaml
# docker-compose.yml
services:
  mysql:
    image: mysql:8.0.39
    container_name: haizhou-mysql
    ports:
      - "3306:3306"
    environment:
      MYSQL_ROOT_PASSWORD: root123
      MYSQL_DATABASE: ruoyi_vue_pro
    volumes:
      - ./docker/mysql/data:/var/lib/mysql
      - ./docker/mysql/init:/docker-entrypoint-initdb.d
    restart: unless-stopped

  redis:
    image: redis:8
    container_name: haizhou-redis
    ports:
      - "6379:6379"
    volumes:
      - ./docker/redis/data:/data
    command: redis-server --appendonly yes
    restart: unless-stopped
```

- [ ] 创建 `docker-compose.yml`（内容如上）
- [ ] 启动所有中间件：
  ```bash
  docker compose up -d
  ```
- [ ] 验证：
  ```bash
  docker compose ps   # 两个容器均为 running
  ```

> **说明**：`./docker/` 目录会自动创建，数据持久保存在本地，`docker compose down` 后重新 `up` 数据不会丢失。

## 注意事项

1. **微信登录本地调试**：小程序在开发者工具中，需勾选"不校验合法域名"
2. **数据库字符集**：必须是 `utf8mb4`，否则中文存储会乱码
3. **Redis 连接**：若 Redis 未启动，后端启动会失败
4. **端口冲突**：后端默认 8080，前端默认 80，确认无冲突
5. **配置文件安全**：`application-local.yaml` 含数据库密码，确认已在 `.gitignore` 中（ruoyi-vue-pro 默认已排除，提交前 `git status` 核查）
6. **中间件管理**：开发时用 `docker compose up -d` 启动，`docker compose stop` 暂停，数据不会丢失
