## 1. 微信登录（复用 member 模块）

### 1.1 后端改造（会员模块扩展）

ruoyi-vue-pro 的 `member` 模块已内置微信小程序登录逻辑，主要工作是扩展首次登录时的逻辑。

- [ ] 找到 `MemberAuthServiceImpl.weixinMiniAppLogin()` 方法
- [ ] 在**首次登录创建用户**后，添加推荐码生成逻辑：

```java
// 首次登录，生成推荐码
if (isNewUser) {
    String referralCode = generateReferralCode(memberUser.getId());
    memberUserMapper.updateReferralCode(memberUser.getId(), referralCode);
    
    // 保存 openid（用于自推检测）
    memberUserMapper.updateOpenId(memberUser.getId(), openid);
    
    // 若 URL 中携带了 referral_code 参数，记录被推荐关系
    if (StrUtil.isNotBlank(reqVO.getReferralCode())) {
        MemberUserDO referrer = memberUserMapper.selectByReferralCode(reqVO.getReferralCode());
        if (referrer != null && !referrer.getId().equals(memberUser.getId())) {
            memberUserMapper.updateReferredBy(memberUser.getId(), referrer.getId());
        }
    }
}
```

- [ ] 实现 `generateReferralCode()` 方法：

```java
private String generateReferralCode(Long memberId) {
    // 格式：REF-{memberId}-{4位大写随机码}
    // 示例：REF-12345-XKJT
    // 优点：可读性强，客服可人工核对，memberId 保证全局唯一
    String randomSuffix = RandomUtil.randomStringUpper(4);
    return "REF-" + memberId + "-" + randomSuffix;
}
```

> **注意**：推荐码格式以 `分佣流程.md` 为准（`REF-{student_id}-{4位随机码}`），便于客服通过推荐码反查推荐人。

- [ ] 修改登录接口 VO，增加 `referralCode` 入参字段
- [ ] 扩展 `MemberUserRespVO`，返回当前用户的 `referralCode`、`isReferralBanned`、`isBanned` 字段

### 1.2 验证登录流程
