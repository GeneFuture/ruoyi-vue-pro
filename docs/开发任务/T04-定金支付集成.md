## 3. 支付成功回调处理（核心）

这是整个系统最关键的代码，所有业务事件从这里触发。

### 3.1 实现 PayOrderHandler

- [ ] 创建 `DepositPayOrderHandler` 实现 ruoyi-pay 的回调接口：

```java
@Component
public class DepositPayOrderHandler implements PayOrderHandler {
    
    @Override
    public String getMerchantOrderIdPrefix() {
        return "DEPOSIT-";  // 与订单号前缀匹配
    }
    
    @Override
    @Transactional(rollbackFor = Exception.class)
    public void handleOrder(PayOrderDO payOrder) {
        String orderNo = payOrder.getMerchantOrderId();
        
        // 1. 查询报名订单
        EnrollmentOrderDO order = enrollmentOrderMapper.selectByOrderNo(orderNo);
        if (order == null) {
            log.error("[handleDepositPaid] 订单不存在: {}", orderNo);
            return;
        }
        
        // 2. 幂等检查（只处理 PENDING 状态）
        int updated = enrollmentOrderMapper.updateStatusIfPending(
            order.getId(), OrderStatusEnum.PAID);
        if (updated == 0) {
            log.warn("[handleDepositPaid] 订单已处理，跳过: {}", orderNo);
            return;
        }
        
        // 3. 验证支付金额（防止篡改）
        BigDecimal paidAmount = BigDecimal.valueOf(payOrder.getPrice()).divide(HUNDRED);
        if (paidAmount.compareTo(order.getAmount()) != 0) {
            log.error("[handleDepositPaid] 支付金额不匹配！订单={}, 期望={}, 实际={}",
                orderNo, order.getAmount(), paidAmount);
            // 不更新状态，触发告警，人工处理
            alarmService.sendAlert("支付金额不匹配: " + orderNo);
            return;
        }
        
        // 4. 更新报名状态 → DEPOSITED
        enrollmentMapper.updateStatus(order.getEnrollmentId(), 
            EnrollmentStatusEnum.DEPOSITED);
        
        // 5. 授予推荐权
        enrollmentMapper.updateReferralRightGranted(order.getEnrollmentId(), true);
        
        // 6. 初始化佣金账户（若不存在）
        commissionAccountService.initAccountIfAbsent(enrollment.getMemberId());
        
        // 7. 建立推荐关系（若有推荐码）
        referralService.establishRelationIfPresent(order.getEnrollmentId());
        
        // 8. 处理拼团（若参与了拼团）
        grouponService.handleMemberPaid(order.getEnrollmentId());
        
        // 9. 发送通知（异步，不影响主流程）
        applicationEventPublisher.publishEvent(new DepositPaidEvent(order.getEnrollmentId()));
    }
}
```

### 3.2 推荐关系建立（在回调中触发）

**文件**：`ReferralServiceImpl.establishRelationIfPresent()`

- [ ] 实现逻辑：
  ```java
  public void establishRelationIfPresent(Long enrollmentId) {
      EnrollmentDO enrollment = enrollmentMapper.selectById(enrollmentId);
      if (StrUtil.isBlank(enrollment.getReferralCodeUsed())) return;  // 无推荐码
      
      // 查推荐人
      MemberUserDO referrer = memberUserMapper.selectByReferralCode(
          enrollment.getReferralCodeUsed());
      if (referrer == null) {
          log.warn("[referral] 推荐码不存在: {}", enrollment.getReferralCodeUsed());
          return;
      }
      
      // 风控检查
      RiskCheckResult riskResult = riskCheckService.check(referrer.getId(), enrollmentId);
      
      if (!riskResult.isPassed()) {
          log.info("[referral] 风控拦截 enrollmentId={}, reason={}", 
              enrollmentId, riskResult.getReason());
          // 记录无效推荐关系（用于审计）
          referralRelationMapper.insertInvalid(referrer.getId(), enrollmentId, 
              riskResult.getReason());
          return;
      }
      
      // 建立推荐关系
      referralRelationMapper.insert(new ReferralRelationDO()
          .setReferrerMemberId(referrer.getId())
          .setReferredEnrollmentId(enrollmentId)
          .setReferredMemberId(enrollment.getMemberId())
          .setSessionId(enrollment.getSessionId())
          .setRelationStatus(ReferralStatusEnum.ACTIVE.getStatus()));
      
      // 更新被推荐人的 referred_by_id
      memberUserMapper.updateReferredBy(enrollment.getMemberId(), referrer.getId());
  }
  ```

## 4. 支付超时关闭（定时任务）

### 4.1 定时任务配置

- [ ] **文件**：`OrderExpireJob.java`

```java
@Slf4j
@JobHandler(value = "orderExpireJob")
@Component
public class OrderExpireJob implements IJobHandler {
    
    @Override
    public ReturnT<String> execute(String param) {
        // 查询已过期的 PENDING 订单（expire_time < now，每5分钟执行一次）
        List<EnrollmentOrderDO> expiredOrders = enrollmentOrderMapper
            .selectExpiredPendingOrders(LocalDateTime.now());
        
        for (EnrollmentOrderDO order : expiredOrders) {
            try {
                enrollmentService.closeExpiredOrder(order.getId());
            } catch (Exception e) {
                log.error("[orderExpireJob] 关闭订单失败: {}", order.getId(), e);
            }
        }
        return ReturnT.SUCCESS;
    }
}
```

- [ ] 在 XXL-JOB 控制台配置：
  - JobHandler：`orderExpireJob`
  - Cron：`0 */5 * * * ?`（每5分钟）
  - 执行策略：单机串行

### 4.2 关闭订单逻辑

```java
@Transactional
public void closeExpiredOrder(Long orderId) {
    // CAS 更新，只处理 PENDING
    int updated = enrollmentOrderMapper.updateStatusIfPending(orderId, OrderStatusEnum.CLOSED);
    if (updated == 0) return;
    
    // 取消关联的 pay 模块订单
    EnrollmentOrderDO order = enrollmentOrderMapper.selectById(orderId);
    if (order.getPayOrderId() != null) {
        payOrderService.cancelPayOrder(order.getPayOrderId());
    }
    
    // 若报名仍是 PENDING_DEPOSIT，取消报名，归还名额
    EnrollmentDO enrollment = enrollmentMapper.selectById(order.getEnrollmentId());
    if (EnrollmentStatusEnum.PENDING_DEPOSIT.equals(enrollment.getEnrollmentStatus())) {
        enrollmentMapper.updateStatus(enrollment.getId(), EnrollmentStatusEnum.CANCELLED);
        sessionMapper.decrementEnrolledCount(enrollment.getSessionId());
    }
}
```
