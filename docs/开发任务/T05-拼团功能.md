## 目标

实现 3 人拼团逻辑：学员报名时可选择参团（加入已有拼团或新建拼团），24 小时内凑满 3 人则成团享优惠，超时未成团则降级（按原价继续）。

---

## 业务规则

```
1. 拼团在【填写报名信息页】时选择（报名和参团同时发生）
2. 报名创建时关联拼团记录（joinGroupon=true）
3. 拼团优惠只影响定金金额（定金 = 标准定金 - groupon_discount_amount）
4. 拼团状态：
   - IN_PROGRESS：进行中（未满3人，且未超24h）
   - SUCCESS：已成团（满3人）
   - DEGRADED：降级（超时未成团，按原价继续报名）
5. 成团时机：第3人支付定金成功时立即标记成功
6. 超时降级：每5分钟扫描一次，超时则降级
7. 降级后原已参团成员：继续报名，但不享受拼团优惠价（差价由退款补偿或不补偿，按业务决策）
   → 本期实现：降级后参团成员按拼团价支付定金，差价不补偿（简化处理）
```

## 2. 拼团 Service 实现

### 2.1 加入或创建拼团

**文件**：`GrouponServiceImpl.joinOrCreateGroupon()`

```java
@Transactional
public GrouponProcessResult joinOrCreateGroupon(
        Long enrollmentId, String inviteCode, Long sessionId) {
    
    GrouponRecordDO grouponRecord;
    
    if (StrUtil.isNotBlank(inviteCode)) {
        // 加入已有拼团
        grouponRecord = grouponRecordMapper.selectByInviteCode(inviteCode);
        validateCanJoin(grouponRecord, enrollmentId);  // 校验：拼团存在、未超时、未满、当前班期匹配
    } else {
        // 新建拼团
        SessionFeeConfigDO feeConfig = feeConfigService.getBySessionId(sessionId);
        if (!feeConfig.getIsGrouponEnabled()) {
            throw exception(GROUPON_NOT_ENABLED);
        }
        grouponRecord = createGrouponRecord(enrollmentId, sessionId, feeConfig);
    }
    
    // 原子加入（Redis INCR + 数据库记录）
    Long count = redisTemplate.opsForValue()
        .increment("groupon:" + grouponRecord.getId() + ":count");
    
    if (count > grouponRecord.getRequiredCount()) {
        // 超员（并发情况），回滚 Redis 计数
        redisTemplate.opsForValue().decrement("groupon:" + grouponRecord.getId() + ":count");
        throw exception(GROUPON_FULL);
    }
    
    // 写入 groupon_member
    grouponMemberMapper.insert(new GrouponMemberDO()
        .setGrouponRecordId(grouponRecord.getId())
        .setEnrollmentId(enrollmentId)
        .setMemberId(getEnrollmentMemberId(enrollmentId)));
    
    // 更新数据库计数
    grouponRecordMapper.incrementCount(grouponRecord.getId());
    
    // 如果达到目标人数，立即成团
    if (count >= grouponRecord.getRequiredCount()) {
        succeedGroupon(grouponRecord.getId());
    }
    
    return new GrouponProcessResult(grouponRecord.getId(), grouponRecord.getInviteCode());
}
```

### 2.2 创建新拼团记录

```java
private GrouponRecordDO createGrouponRecord(
        Long enrollmentId, Long sessionId, SessionFeeConfigDO feeConfig) {
    
    GrouponRecordDO record = new GrouponRecordDO()
        .setSessionId(sessionId)
        .setInviteCode(generateInviteCode())  // 8位随机大写字母+数字
        .setInitiatorEnrollmentId(enrollmentId)
        .setRequiredCount(feeConfig.getGrouponRequiredCount())
        .setCurrentCount(0)  // 后续 increment 操作更新
        .setGrouponStatus(GrouponStatusEnum.IN_PROGRESS.getStatus())
        .setExpireTime(LocalDateTime.now().plusHours(feeConfig.getGrouponExpireHours()));
    
    grouponRecordMapper.insert(record);
    
    // 设置 Redis TTL（用于快速倒计时检测，数据库 expire_time 是最终依据）
    redisTemplate.opsForValue().set(
        "groupon:" + record.getId() + ":count", 0,
        feeConfig.getGrouponExpireHours(), TimeUnit.HOURS);
    
    return record;
}
```

### 2.3 拼团成功处理

```java
@Transactional
public void succeedGroupon(Long grouponRecordId) {
    // CAS 更新，防重复处理
    int updated = grouponRecordMapper.updateStatusIfInProgress(
        grouponRecordId, GrouponStatusEnum.SUCCESS);
    if (updated == 0) return;
    
    grouponRecordMapper.updateSuccessTime(grouponRecordId, LocalDateTime.now());
    
    // 发布拼团成功事件（通知所有成员）
    applicationEventPublisher.publishEvent(new GrouponSuccessEvent(grouponRecordId));
}
```

## 3. 拼团超时定时任务

**文件**：`GrouponExpireJob.java`

- [ ] 创建定时任务：

```java
@JobHandler(value = "grouponExpireJob")
@Component
public class GrouponExpireJob implements IJobHandler {
    
    @Override
    public ReturnT<String> execute(String param) {
        // 查询已超时的 IN_PROGRESS 拼团
        List<GrouponRecordDO> expiredRecords = grouponRecordMapper
            .selectExpiredInProgress(LocalDateTime.now());
        
        for (GrouponRecordDO record : expiredRecords) {
            try {
                grouponService.degradeGroupon(record.getId());
            } catch (Exception e) {
                log.error("[grouponExpireJob] 拼团降级失败: {}", record.getId(), e);
            }
        }
        return ReturnT.SUCCESS;
    }
}
```

- [ ] 实现 `degradeGroupon()`：

```java
@Transactional
public void degradeGroupon(Long grouponRecordId) {
    // CAS 更新
    int updated = grouponRecordMapper.updateStatusIfInProgress(
        grouponRecordId, GrouponStatusEnum.DEGRADED);
    if (updated == 0) return;
    
    log.info("[groupon] 拼团降级: recordId={}", grouponRecordId);
    
    // 发布降级事件（通知成员：拼团未成功，报名继续，无优惠）
    applicationEventPublisher.publishEvent(new GrouponDegradedEvent(grouponRecordId));
}
```
