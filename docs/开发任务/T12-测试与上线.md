## 1. 联调测试

### 1.1 核心流程端到端测试

按以下场景逐一测试（真机 + 真实账号）：

#### 场景 A：基础报名 + 定金支付

```
1. 打开小程序，微信登录
2. 浏览课程列表，选择班期
3. 查看班期详情，确认费用
4. 填写报名信息，提交
5. 发起定金支付（真实小额，如 1 分钱测试）
6. 支付成功，查看报名状态 → DEPOSITED
7. 检查：member_user.referral_right_granted = true
8. 个人中心 → 我的推荐 → 看到推荐码
```

#### 场景 B：推荐链接 + 佣金触发

```
1. A 用户登录，获取推荐码
2. A 用户分享链接给 B 用户
3. B 用户点击链接进入小程序，URL 携带推荐码
4. B 用户报名并支付定金
5. 检查：referral_relation 记录创建
6. （若无尾款）检查：commission_record 创建，status=PENDING_REVIEW
7. 管理后台：审核通过佣金
8. 等待 T+1（或手动触发定时任务）
9. A 用户查看佣金账户：已发放
```

#### 场景 C：拼团流程

```
1. 班期开启拼团
2. A 用户报名，选择"新建拼团"，支付定金
3. A 用户分享拼团邀请码
4. B 用户加入拼团，支付定金
5. C 用户加入拼团，支付定金 → 第3人，拼团成功
6. 检查：groupon_record.status = SUCCESS
7. 三人均收到"拼团成功"通知
8. 等待超时测试：仅2人加入，24h后定时任务降级
```

#### 场景 D：退费流程

```
1. 学员报名并支付定金
2. 学员申请退费，填写原因
3. 管理员审核，批准退款金额
4. 检查：微信退款到账（需等待 1-5 分钟）
5. 检查：enrollment.status = CANCELLED
6. 检查：session.enrolled_count 已减少
```

#### 场景 E：风控检测

```
1. A 用户分享推荐码
2. A 用户用同一微信账号注册新手机号，用自己的推荐码报名
3. 检查：推荐关系被拒绝（自推检测）
4. 添加某手机号到黑名单
5. 用该手机号报名（可以），但推荐关系被拒绝
```

### 1.2 边界情况测试

- [ ] 班期满员时（enrolled_count = max_students），再次报名返回错误
- [ ] 支付订单 30 分钟过期后，无法支付
- [ ] 已完成支付的订单，重复调用支付接口 → 幂等返回
- [ ] 重复提交推荐关系 → 幂等，不创建重复记录

## 6. 生产环境部署

### 6.1 部署方式

推荐使用 Docker Compose（初期简单方案）：

```yaml
# docker-compose.prod.yml
# 注：Docker Compose v2+ 已不需要 version 字段
services:
  app:
    image: maritime-training:latest
    ports: ["8080:8080"]
    environment:
      SPRING_PROFILES_ACTIVE: prod
      DB_HOST: rds-host
      REDIS_HOST: redis-host
    volumes:
      - ./logs:/app/logs
      - ./pay:/app/pay  # 支付证书
  
  nginx:
    image: nginx:alpine
    ports: ["80:80", "443:443"]
    volumes:
      - ./nginx.conf:/etc/nginx/conf.d/default.conf
      - ./ssl:/etc/ssl
```

### 6.2 Nginx 配置

```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;
    
    ssl_certificate /etc/ssl/cert.pem;
    ssl_certificate_key /etc/ssl/key.pem;
    
    # 后端 API
    location /app-api/ {
        proxy_pass http://app:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
    
    location /admin-api/ {
        proxy_pass http://app:8080;
        # 限制访问 IP（管理端可限制只允许公司 IP）
        # allow 1.2.3.4;
        # deny all;
    }
    
    # 管理前端
    location / {
        root /usr/share/nginx/html;
        try_files $uri $uri/ /index.html;
    }
}
```
