## 业务规则

```
时序（与分佣流程.md 对齐）：
  支付定金 → 授予推荐权 → 建立推荐关系（若有推荐码）
  支付尾款（或全款=定金时）→ 创建佣金记录 WAITING_FOR_CLASS
                              expected_settle_date = 开课日期 + 7天
  开课后第 7 天，定时任务触发（见 T08）：
    ├─ 检查被推荐人是否在 7 天内发起退费
    │   ├─ 有退费 → 佣金状态 → FROZEN（冻结，人工处理）
    │   └─ 无退费 → 佣金状态 → PENDING_REVIEW（进审核）
  管理员审核通过 → PENDING_PAYOUT
  T+1 定时任务 → 企业付款 → PAID

重要说明：
  - 佣金成功条件 = 全款支付 + 开课后 7 天无退费（两者缺一不可）
  - 全款支付时仅创建"待开课"记录，不代表佣金一定会发放
  - 推荐人收到通知时机：开课后 7 天审核通过，而非全款支付时

风控规则（硬编码，不可配置）：
  Rule 1: 自推检测
    - 推荐人 openid == 被推荐人 openid → 拒绝
    - 推荐人 phone == 被推荐人 phone → 拒绝
    - 推荐人 member_id == 被推荐人 member_id → 拒绝
  Rule 2: 手机号黑名单
    - 被推荐人 phone 在 risk_blacklist 中 → 拒绝推荐（报名继续）
  Rule 3: 批量推荐检测（Phase 2 实现，本期预留接口）
    - 24h 内推荐超过 N 人 → 标记异常，触发人工审核

注意：风控只影响推荐关系，不影响报名和支付流程。
```

## 2. 风控检查 Service

**文件**：`RiskCheckServiceImpl.java`

- [ ] 实现 `check(referrerId, enrollmentId)`：

```java
public RiskCheckResult check(Long referrerId, Long enrollmentId) {
    EnrollmentDO enrollment = enrollmentMapper.selectById(enrollmentId);
    MemberUserDO referrer = memberUserMapper.selectById(referrerId);
    MemberUserDO referred = memberUserMapper.selectById(enrollment.getMemberId());
    
    // Rule 1a: 同一 member_id
    if (referrerId.equals(enrollment.getMemberId())) {
        return RiskCheckResult.fail("自推：推荐人与被推荐人为同一账号");
    }
    
    // Rule 1b: 同一 openid
    if (StrUtil.isNotBlank(referrer.getOpenId())
            && referrer.getOpenId().equals(referred.getOpenId())) {
        return RiskCheckResult.fail("自推：推荐人与被推荐人使用相同微信账号");
    }
    
    // Rule 1c: 同一手机号
    // 注意：两个手机号都是加密存储，加密后比对
    if (StrUtil.isNotBlank(referrer.getMobile())
            && referrer.getMobile().equals(
                AesUtils.encrypt(enrollment.getPhone()))) {
        return RiskCheckResult.fail("自推：推荐人与被推荐人使用相同手机号");
    }
    
    // Rule 2: 被推荐人手机号在黑名单中
    boolean inBlacklist = riskBlacklistMapper
        .existsByPhone(AesUtils.encrypt(enrollment.getPhone()));
    if (inBlacklist) {
        return RiskCheckResult.fail("被推荐人手机号在风控黑名单中");
    }
    
    // Rule 3: 批量推荐检测（Phase 2 实现，本期返回通过）
    // TODO: Phase 2 实现
    
    return RiskCheckResult.pass();
}
```

### 4.1 触发时机

有两种情况：
1. **有尾款**：尾款支付成功后触发
2. **无尾款（定金=全款）**：定金支付成功后触发

- [ ] 在 `DepositPayOrderHandler` 中，判断是否需要立即触发佣金：
  ```java
  SessionFeeConfigDO feeConfig = feeConfigService.getBySessionId(enrollment.getSessionId());
  BigDecimal remainBalance = feeConfig.getTuitionAmount().subtract(feeConfig.getDepositAmount());
  
  if (remainBalance.compareTo(BigDecimal.ZERO) <= 0) {
      // 全款=定金，立即触发佣金
      commissionService.triggerCommissionIfEligible(enrollment.getId());
  }
  // else：等待尾款支付后触发（在 BalancePayOrderHandler 中实现，见 T07）
  ```

### 4.2 佣金触发 Service

**文件**：`CommissionServiceImpl.triggerCommissionIfEligible()`

```java
@Transactional
public void triggerCommissionIfEligible(Long enrollmentId) {
    // 查推荐关系
    ReferralRelationDO relation = referralRelationMapper
        .selectByReferredEnrollmentId(enrollmentId);
    if (relation == null || !ReferralStatusEnum.ACTIVE.equals(relation.getRelationStatus())) {
        return;  // 没有有效推荐关系
    }
    
    // 防重复：已存在佣金记录则跳过
    if (commissionRecordMapper.existsByReferredEnrollmentId(enrollmentId)) {
        return;
    }
    
    // 获取佣金金额（从班期费用配置）
    SessionFeeConfigDO feeConfig = feeConfigService.getBySessionId(relation.getSessionId());
    
    // 获取开课日期，计算预计结算日（开课日期 + 7天）
    CourseSessionDO session = sessionMapper.selectById(relation.getSessionId());
    LocalDate expectedSettleDate = session.getStartDate().plusDays(7);
    
    // 创建佣金记录（初始状态：WAITING_FOR_CLASS 待开课）
    // ⚠️ 注意：此时佣金还不确认，需等开课后 7 天无退费才进入审核
    CommissionRecordDO record = new CommissionRecordDO()
        .setReferrerMemberId(relation.getReferrerMemberId())
        .setReferredEnrollmentId(enrollmentId)
        .setSessionId(relation.getSessionId())
        .setCommissionAmount(feeConfig.getReferralCommissionAmount())
        .setCommissionStatus(CommissionStatusEnum.WAITING_FOR_CLASS.getStatus())  // 待开课
        .setExpectedSettleDate(expectedSettleDate)  // 开课日期 + 7天
        .setTriggerTime(LocalDateTime.now());
    
    commissionRecordMapper.insert(record);
    
    // 注意：此时不更新推荐人账户金额，等审核通过后再更新
    // （避免佣金显示为"待发放"但最终因退费被冻结而引发用户误解）
    
    log.info("[commission] 佣金记录已创建，等待开课: enrollmentId={}, expectedSettleDate={}",
        enrollmentId, expectedSettleDate);
}
```

> **与旧版的关键差别**：
> - 旧版直接创建 `PENDING_REVIEW`，推荐人立刻看到"审核中"字样
> - 新版创建 `WAITING_FOR_CLASS`，开课后 7 天无退费才进入审核
> - 推荐人在此阶段看到的状态是"等待开课结算"，预计发放日期 = `expectedSettleDate`
