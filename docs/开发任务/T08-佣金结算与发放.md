## 1. 开课后 7 天结算检查任务（新增）

> 这是触发佣金从"待开课"进入"审核"的关键步骤。

### 1.1 任务逻辑

**文件**：`CommissionSettleCheckJob.java`

```java
@Slf4j
@JobHandler(value = "commissionSettleCheckJob")
@Component
public class CommissionSettleCheckJob implements IJobHandler {
    
    @Override
    public ReturnT<String> execute(String param) {
        // 查询 status = WAITING_FOR_CLASS
        // 且 expected_settle_date <= today（已到结算日期）
        LocalDate today = LocalDate.now();
        
        int page = 0;
        int pageSize = 100;
        int totalProcessed = 0;
        
        while (true) {
            List<CommissionRecordDO> records = commissionRecordMapper
                .selectWaitingForClassAndDue(today, page * pageSize, pageSize);
            
            if (records.isEmpty()) break;
            
            for (CommissionRecordDO record : records) {
                try {
                    commissionService.processSettleCheck(record.getId());
                    totalProcessed++;
                } catch (Exception e) {
                    log.error("[settleCheck] 处理失败: recordId={}", record.getId(), e);
                }
            }
            
            page++;
            if (records.size() < pageSize) break;
        }
        
        log.info("[commissionSettleCheckJob] 本次处理 {} 条待结算佣金", totalProcessed);
        return ReturnT.SUCCESS;
    }
}
```

### 1.2 结算检查逻辑

**文件**：`CommissionServiceImpl.processSettleCheck()`

```java
@Transactional
public void processSettleCheck(Long recordId) {
    // 幂等：只处理 WAITING_FOR_CLASS 状态
    CommissionRecordDO record = commissionRecordMapper.selectById(recordId);
    if (!CommissionStatusEnum.WAITING_FOR_CLASS.getStatus()
            .equals(record.getCommissionStatus())) {
        return;
    }
    
    // 检查被推荐人是否在开课 7 天内发起退费
    boolean hasRefundInWindow = refundApplyMapper.existsByEnrollmentIdAndCreateTimeBefore(
        record.getReferredEnrollmentId(),
        record.getExpectedSettleDate()  // 开课后 7 天内
    );
    
    if (hasRefundInWindow) {
        // 有退费 → 冻结佣金，人工处理
        commissionRecordMapper.updateStatus(recordId,
            CommissionStatusEnum.FROZEN.getStatus());
        
        // 通知管理员
        alarmService.sendAlert("佣金因退费被冻结，需人工确认，recordId=" + recordId);
        
        log.info("[settleCheck] 佣金冻结（退费原因）: recordId={}", recordId);
        
    } else {
        // 无退费 → 进入审核队列
        commissionRecordMapper.updateStatusAndSettleTime(recordId,
            CommissionStatusEnum.PENDING_REVIEW.getStatus(),
            LocalDateTime.now());
        
        // 更新推荐人账户（此时才计入 pending_amount）
        commissionAccountService.addPendingAmount(
            record.getReferrerMemberId(), record.getCommissionAmount());
        
        // 通知推荐人：佣金审核中
        applicationEventPublisher.publishEvent(
            new CommissionReadyForReviewEvent(record.getReferrerMemberId(), recordId));
        
        log.info("[settleCheck] 佣金进入审核: recordId={}", recordId);
    }
    
    // 记录检查时间
    commissionRecordMapper.updateSettleCheckTime(recordId, LocalDateTime.now());
}
```

## 2. T+1 佣金发放定时任务

### 2.1 任务逻辑

**文件**：`CommissionPayoutJob.java`

```java
@Slf4j
@JobHandler(value = "commissionPayoutJob")
@Component
public class CommissionPayoutJob implements IJobHandler {
    
    @Override
    public ReturnT<String> execute(String param) {
        // 发放条件：
        // status = PENDING_PAYOUT
        // approve_time < now() - 24h（审核通过超过 24 小时，即 T+1）
        
        LocalDateTime threshold = LocalDateTime.now().minusHours(24);
        
        int page = 0;
        int pageSize = 50;
        int totalProcessed = 0;
        
        while (true) {
            List<CommissionRecordDO> records = commissionRecordMapper
                .selectPendingPayoutBefore(threshold, page * pageSize, pageSize);
            
            if (records.isEmpty()) break;
            
            for (CommissionRecordDO record : records) {
                try {
                    commissionService.payoutCommission(record.getId());
                    totalProcessed++;
                } catch (Exception e) {
                    log.error("[commissionPayoutJob] 佣金发放失败: recordId={}", record.getId(), e);
                }
            }
            
            page++;
            if (records.size() < pageSize) break;
        }
        
        log.info("[commissionPayoutJob] 本次发放 {} 条佣金", totalProcessed);
        return ReturnT.SUCCESS;
    }
}
```

@Transactional
public void payoutCommission(Long recordId) {
    CommissionRecordDO record = commissionRecordMapper.selectById(recordId);
    
    // 幂等：只处理 PENDING_PAYOUT 状态
    int updated = commissionRecordMapper.updateStatusIfPendingPayout(
        recordId, CommissionStatusEnum.PAYING);
    if (updated == 0) {
        log.warn("[payout] 佣金非 PENDING_PAYOUT 状态，跳过: {}", recordId);
        return;
    }
    
    // 获取推荐人 openid（企业付款需要 openid）
    MemberUserDO referrer = memberUserMapper.selectById(record.getReferrerMemberId());
    if (StrUtil.isBlank(referrer.getOpenId())) {
        markPayoutFailed(recordId, "推荐人 openid 为空，无法发起企业付款");
        return;
    }
    
    // 计算税后实际到账金额
    BigDecimal netAmount = taxService.calculateNetAmount(
        record.getReferrerMemberId(), record.getCommissionAmount());
    
    try {
        // 调用微信企业付款（通过 ruoyi-pay 的转账接口）
        payTransferService.transfer(new PayTransferCreateReqDTO()
            .setAppId(PAY_APP_ID)
            .setChannelCode(PayChannelEnum.WX_TRANSFER.getCode())
            .setMerchantTransferId(generateTransferId(recordId))
            .setType(PayTransferTypeEnum.WECHAT_BALANCE.getType())
            .setOpenid(referrer.getOpenId())
            .setPrice(netAmount.multiply(BigDecimal.valueOf(100)).intValue())  // 转分
            .setSubject("海员培训推荐佣金")
            .setRemark("推荐佣金（税后）"));
        
        // 发放成功，更新账户
        commissionRecordMapper.updatePaid(recordId, LocalDateTime.now());
        commissionAccountService.confirmPayout(
            record.getReferrerMemberId(), record.getCommissionAmount());
        
        // 通知推荐人：佣金已到账
        applicationEventPublisher.publishEvent(
            new CommissionPaidEvent(record.getReferrerMemberId(), record.getId(), netAmount));
        
    } catch (Exception e) {
        log.error("[payout] 企业付款调用失败: recordId={}", recordId, e);
        markPayoutFailed(recordId, e.getMessage());
    }
}

private void markPayoutFailed(Long recordId, String reason) {
    commissionRecordMapper.updateFailed(recordId, reason);
    alarmService.sendAlert("佣金发放失败，需人工处理，recordId=" + recordId);
}
```

## 3. 提现功能（学员主动申请）

> 与"自动发放"的区别：自动发放是系统主动打款，提现是学员主动申请从账户余额中提取。

@Transactional
public AppWithdrawalApplyRespVO applyWithdrawal(Long memberId, AppWithdrawalApplyReqVO reqVO) {
    
    // 1. 金额范围校验（100 ≤ amount ≤ 1000）
    if (reqVO.getAmount().compareTo(new BigDecimal("100")) < 0) {
        throw exception(WITHDRAWAL_AMOUNT_TOO_SMALL);  // 最低 100 元
    }
    if (reqVO.getAmount().compareTo(new BigDecimal("1000")) > 0) {
        throw exception(WITHDRAWAL_AMOUNT_TOO_LARGE);  // 单次最高 1000 元
    }
    
    // 2. 账户余额校验
    CommissionAccountDO account = commissionAccountService.getAccount(memberId);
    if (account.getPendingAmount().compareTo(reqVO.getAmount()) < 0) {
        throw exception(WITHDRAWAL_INSUFFICIENT_BALANCE);
    }
    
    // 3. 账户状态校验
    MemberUserDO member = memberUserMapper.selectById(memberId);
    if (!MemberStatusEnum.ACTIVE.equals(member.getStatus())) {
        throw exception(WITHDRAWAL_ACCOUNT_FROZEN);
    }
    
    // 4. 冻结期校验（首次定金支付后 7 天内不可提现）
    LocalDateTime firstDepositTime = enrollmentMapper.getFirstDepositTime(memberId);
    if (firstDepositTime != null && firstDepositTime.plusDays(7).isAfter(LocalDateTime.now())) {
        throw exception(WITHDRAWAL_IN_FREEZE_PERIOD);
    }
    
    // 5. 本月提现次数校验（≤ 5 次）
    YearMonth currentMonth = YearMonth.now();
    int monthCount = withdrawalMapper.countByMemberAndMonth(memberId, currentMonth);
    if (monthCount >= 5) {
        throw exception(WITHDRAWAL_MONTHLY_LIMIT_EXCEEDED);
    }
    
    // 6. 24h 累计金额校验（≤ 10000 元）
    LocalDateTime last24h = LocalDateTime.now().minusHours(24);
    BigDecimal last24hTotal = withdrawalMapper.sumSuccessAmountSince(memberId, last24h);
    if (last24hTotal.add(reqVO.getAmount()).compareTo(new BigDecimal("10000")) > 0) {
        throw exception(WITHDRAWAL_DAILY_LIMIT_EXCEEDED);
    }
    
    // 7. 无进行中的提现申请
    if (withdrawalMapper.existsPendingByMember(memberId)) {
        throw exception(WITHDRAWAL_PENDING_EXISTS);
    }
    
    // 计算税额
    BigDecimal taxAmount = taxService.calculateTax(memberId, reqVO.getAmount());
    BigDecimal netAmount = reqVO.getAmount().subtract(taxAmount);
    
    // 创建提现申请
    WithdrawalApplyDO apply = new WithdrawalApplyDO()
        .setMemberId(memberId)
        .setApplyAmount(reqVO.getAmount())
        .setTaxAmount(taxAmount)
        .setNetAmount(netAmount)
        .setChannel(reqVO.getChannel())
        .setApplyStatus(WithdrawalStatusEnum.PENDING.getStatus());
    
    withdrawalMapper.insert(apply);
    
    // 冻结账户余额
    commissionAccountService.freezeAmount(memberId, reqVO.getAmount());
    
    // ≤ 1000 元自动审批，>1000 元进人工队列（此处 ≤ 1000 已在前面校验，实际都自动审批）
    withdrawalService.autoApproveAndPay(apply.getId());
    
    return new AppWithdrawalApplyRespVO()
        .setApplyId(apply.getId())
        .setNetAmount(netAmount)
        .setTaxAmount(taxAmount)
        .setEstimatedArrivalDesc(
            WithdrawalChannelEnum.WX_BALANCE.equals(reqVO.getChannel())
                ? "预计 T+1 到账" : "预计 2-3 工作日到账");
}
```

### 4.2 税务计算逻辑

**文件**：`TaxServiceImpl.java`

```java
/**
 * 计算本次发放的代扣税额（按自然月累计规则）
 *
 * 规则：
 *   IF 月累计到账 ≤ 800 元 → 免税
 *   ELSE → 代扣税 = (月累计 - 800) × 20%（累进计算，避免重复征税）
 *
 * 示例：
 *   当月已到账 700 元，本次发放 500 元
 *   → 月累计 = 1200 元
 *   → 应扣税 = (1200 - 800) × 20% = 80 元
 *   → 已扣税 = (700 - 800) × 20% = 0 元（因为 700 ≤ 800，之前未扣）
 *   → 本次扣税 = 80 - 0 = 80 元
 */
@Transactional
public BigDecimal calculateAndRecordTax(Long memberId, BigDecimal payoutAmount) {
    String taxMonth = YearMonth.now().toString();  // "2026-06"
    
    // 获取或创建当月税务记录（乐观锁更新）
    TaxRecordDO taxRecord = taxRecordMapper.selectOrCreate(memberId, taxMonth);
    
    BigDecimal monthIncomeBefore = taxRecord.getMonthIncome();
    BigDecimal monthIncomeAfter = monthIncomeBefore.add(payoutAmount);
    
    // 计算已应扣税和新应扣税（累进）
    BigDecimal EXEMPT = new BigDecimal("800");
    BigDecimal TAX_RATE = new BigDecimal("0.2");
    
    BigDecimal taxBefore = monthIncomeBefore.compareTo(EXEMPT) <= 0
        ? BigDecimal.ZERO
        : monthIncomeBefore.subtract(EXEMPT).multiply(TAX_RATE);
    
    BigDecimal taxAfter = monthIncomeAfter.compareTo(EXEMPT) <= 0
        ? BigDecimal.ZERO
        : monthIncomeAfter.subtract(EXEMPT).multiply(TAX_RATE);
    
    BigDecimal thisTax = taxAfter.subtract(taxBefore).setScale(2, RoundingMode.HALF_UP);
    
    // 乐观锁更新月度记录
    int updated = taxRecordMapper.updateIncrease(
        taxRecord.getId(), payoutAmount, thisTax, taxRecord.getVersion());
    if (updated == 0) {
        throw new OptimisticLockException("税务记录并发更新冲突，请重试");
    }
    
    return thisTax;  // 本次代扣税额
}

/**
 * 计算净到账金额（不更新数据库，用于提现前展示）
 */
public BigDecimal calculateNetAmount(Long memberId, BigDecimal amount) {
    BigDecimal tax = calculateTaxPreview(memberId, amount);
    return amount.subtract(tax);
}
```
