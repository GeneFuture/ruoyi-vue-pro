## 1. 尾款支付

### 1.1 尾款金额计算

```
尾款 = 学费总额 - 已付定金
```

注意：若参与了成功的拼团，定金已减免，但尾款不变（拼团优惠只减定金）。

### 1.2 发起尾款支付接口

**文件**：`AppPayController.java`

```java
public CommonResult<AppPayOrderRespVO> payBalance(

```

- [ ] 创建尾款订单逻辑：
  ```java
  // 查询报名记录，验证状态为 DEPOSITED（已付定金）
  EnrollmentDO enrollment = enrollmentMapper.selectById(reqVO.getEnrollmentId());
  if (!EnrollmentStatusEnum.DEPOSITED.equals(enrollment.getEnrollmentStatus())) {
      throw exception(ENROLLMENT_STATUS_ERROR);
  }
  
  // 查询已付定金金额
  EnrollmentOrderDO depositOrder = enrollmentOrderMapper
      .selectByEnrollmentIdAndTypeAndStatus(
          enrollment.getId(), OrderTypeEnum.DEPOSIT, OrderStatusEnum.PAID);
  
  // 计算尾款
  SessionFeeConfigDO feeConfig = feeConfigService.getBySessionId(enrollment.getSessionId());
  BigDecimal balanceAmount = feeConfig.getTuitionAmount().subtract(depositOrder.getAmount());
  
  if (balanceAmount.compareTo(BigDecimal.ZERO) <= 0) {
      throw exception(BALANCE_NOT_REQUIRED);  // 已全额支付（无需尾款）
  }
  
  // 检查是否已有待支付的尾款订单（防重复创建）
  EnrollmentOrderDO existingBalance = enrollmentOrderMapper
      .selectByEnrollmentIdAndType(enrollment.getId(), OrderTypeEnum.BALANCE);
  if (existingBalance == null) {
      // 创建尾款订单
      existingBalance = createBalanceOrder(enrollment, balanceAmount);
  } else if (OrderStatusEnum.CLOSED.equals(existingBalance.getOrderStatus())) {
      // 上一次订单已关闭，重新创建
      existingBalance = createBalanceOrder(enrollment, balanceAmount);
  }
  
  // 调用 ruoyi-pay（逻辑与定金相同）
  return submitToWxPay(existingBalance);
  ```

```java
    // PENDING_DEPOSIT 直接取消，不走退费流程
    ...

```

- [ ] 申请时：
  1. 创建 `refund_apply` 记录，状态=PENDING
  2. 展示退款政策文本（从 fee_config.refund_policy_text 读取），要求学员确认
  3. 申请后，报名状态 → `MANUAL_PROCESSING`，并生成 `REFUND_APPLY` 人工处理单

### 2.2 管理员审核退费（人工处理）

- [ ] `GET /admin-api/maritime/refund-apply/page`（退费申请列表）
  - 筛选：状态、班期、申请时间

- [ ] `PUT /admin-api/maritime/refund-apply/approve`（登记退款结果）
  - 填写实际退款金额（可与申请金额不同）
  - **退款由人工在微信商户平台完成**，不再调用 pay 退款接口
  - 审核通过后（**必须在同一事务内完成**）：
    1. 更新 `refund_apply.status = REFUNDED` 并记录退款金额
    2. 标记对应支付订单为 `REFUNDED`（全额退款时标记全部已支付订单）
    3. 更新 `enrollment.status = CANCELLED`
    4. 归还班期名额（`enrolled_count - 1`）
    5. 关闭该报名下的人工处理单

- [ ] `PUT /admin-api/maritime/refund-apply/reject`（审核拒绝）
  - 填写拒绝原因
  - 通知学员
  - 关闭 `REFUND_APPLY` 人工单，并按已支付订单恢复报名状态：
    已付尾款/全款 → `PAID_OFF`，仅付定金 → `DEPOSITED`

### 2.3 退款执行方式（人工）

为避免自动退款与人工财务流程冲突，系统**不再调用 pay 模块创建退款单**：

1. 学员在小程序提交退费申请，报名状态立即变为 `MANUAL_PROCESSING`，并生成 `REFUND_APPLY` 人工处理单
2. 管理员在微信商户平台人工操作退款
3. 管理员在后台「退费申请」页点击「审核通过」，填写实际退款金额，登记退款结果
4. 系统同步更新退费申请、支付订单、报名状态、班期名额

> 人工处理单统一在「海员培训 → 人工处理」页面查看；退费类人工单必须在退费申请页处理，不能直接在此页面关闭。

## 3. 尾款催缴提醒（定时任务）

**文件**：`BalanceReminderJob.java`

```java
@JobHandler(value = "balanceReminderJob")
@Component
public class BalanceReminderJob implements IJobHandler {
    
    @Override
    public ReturnT<String> execute(String param) {
        // 每天 10:00 执行
        // 查询 status=DEPOSITED，且对应班期 start_date 在 7 天后的报名记录
        LocalDate reminderDate = LocalDate.now().plusDays(7);
        List<EnrollmentDO> enrollments = enrollmentMapper
            .selectDepositedWithSessionBefore(reminderDate);
        
        for (EnrollmentDO enrollment : enrollments) {
            // 发站内信 + 微信订阅消息：请在 XX 前完成尾款支付
            notifyService.sendBalanceReminder(enrollment);
        }
        return ReturnT.SUCCESS;
    }
}
```

- [ ] 后台「基础设施 → 定时任务」配置（Quartz + MySQL）：
  - Handler：`balanceReminderJob`
  - Cron：`0 0 10 * * ?`（每天10:00）
- [ ] 尾款逾期转人工任务：
  - Handler：`balanceOverdueJob`
  - Cron：`0 0 9 * * ?`（每天09:00）
  - 扫描 `DEPOSITED` 且满足以下任一条件的报名：
    - `balance_due_date < 今天`（尾款截止日期已过）
    - 班期 `start_date <= 今天`（已开班仍未付清，兜底未配置尾款截止日期的情况）
    1. 生成 `BALANCE_OVERDUE` 人工处理单
    2. 报名状态 → `MANUAL_PROCESSING`
    3. 学员补缴尾款后，自动关闭该人工单并转 `PAID_OFF`
