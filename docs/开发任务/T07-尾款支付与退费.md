## 1. 尾款支付

### 1.1 尾款金额计算

```
尾款 = 学费总额 - 已付定金
```

注意：若参与了成功的拼团，定金已减免，但尾款不变（拼团优惠只减定金）。

### 1.2 发起尾款支付接口


- [ ] 创建尾款订单逻辑：
  ```java
  // 查询报名记录，验证状态为 DEPOSITED（已付定金）
  EnrollmentDO enrollment = enrollmentMapper.selectById(reqVO.getEnrollmentId());
  if (!EnrollmentStatusEnum.DEPOSITED.equals(enrollment.getEnrollmentStatus())) {
      throw exception(ENROLLMENT_STATUS_ERROR);
  }
  
  // 查询已付定金金额
  EnrollmentOrderDO depositOrder = enrollmentOrderMapper
      .selectByEnrollmentIdAndTypeAndStatus(
          enrollment.getId(), OrderTypeEnum.DEPOSIT, OrderStatusEnum.PAID);
  
  // 计算尾款
  SessionFeeConfigDO feeConfig = feeConfigService.getBySessionId(enrollment.getSessionId());
  BigDecimal balanceAmount = feeConfig.getTuitionAmount().subtract(depositOrder.getAmount());
  
  if (balanceAmount.compareTo(BigDecimal.ZERO) <= 0) {
      throw exception(BALANCE_NOT_REQUIRED);  // 已全额支付（无需尾款）
  }
  
  // 检查是否已有待支付的尾款订单（防重复创建）
  EnrollmentOrderDO existingBalance = enrollmentOrderMapper
      .selectByEnrollmentIdAndType(enrollment.getId(), OrderTypeEnum.BALANCE);
  if (existingBalance == null) {
      // 创建尾款订单
      existingBalance = createBalanceOrder(enrollment, balanceAmount);
  } else if (OrderStatusEnum.CLOSED.equals(existingBalance.getOrderStatus())) {
      // 上一次订单已关闭，重新创建
      existingBalance = createBalanceOrder(enrollment, balanceAmount);
  }
  
  // 调用 ruoyi-pay（逻辑与定金相同）
  return submitToWxPay(existingBalance);
  ```

```java
@Override
@Transactional
public void handleOrder(PayOrderDO payOrder) {
    String orderNo = payOrder.getMerchantOrderId();
    EnrollmentOrderDO order = enrollmentOrderMapper.selectByOrderNo(orderNo);
    
    // 幂等
    int updated = enrollmentOrderMapper.updateStatusIfPending(
        order.getId(), OrderStatusEnum.PAID);
    if (updated == 0) return;
    
    // 金额校验
    // ...（同定金逻辑）
    
    // 更新报名状态 → IN_PROGRESS（全款已付，等待开班）
    // 注：COMPLETED 状态由班期结束后管理员手动标记或定时任务更新，
    // 此处只代表"付款完成"，不代表"课程完成"
    enrollmentMapper.updateStatus(order.getEnrollmentId(), 
        EnrollmentStatusEnum.IN_PROGRESS);
    
    // 触发佣金（有尾款情况下，在这里触发）
    commissionService.triggerCommissionIfEligible(order.getEnrollmentId());
    
    // 发布事件（通知学员支付成功、通知开班信息等）
    applicationEventPublisher.publishEvent(
        new BalancePaidEvent(order.getEnrollmentId()));
}
```

### 3.2 管理员审核退费

- [ ] `GET /admin-api/maritime/refund/page`（退费申请列表）
  - 筛选：状态、班期、申请时间

- [ ] `PUT /admin-api/maritime/refund/approve`（审核通过）
  - 填写实际退款金额（可与申请金额不同）
  - 选择退款方式：微信原路退款（调用 ruoyi-pay 退款接口）
  - 审核通过后（**必须在同一事务内完成**）：
    1. 调用微信退款
    2. 更新 `enrollment.status = CANCELLED`
    3. 更新 `refund_apply.status = REFUNDED`
    4. 归还班期名额（`enrolled_count - 1`）
    5. 若有推荐关系：标记推荐关系无效（`relation_status = INVALID`）
    6. **若存在对应佣金记录**（状态为 `WAITING_FOR_CLASS` 或 `PENDING_REVIEW`）：
       - 佣金状态 → `FROZEN`（冻结）
       - 更新推荐人账户：若已计入 `pending_amount` 则扣减
       - 通知推荐人："您推荐的学员已退费，对应佣金已冻结，请联系客服"

  ```java
  // 退费审核通过时的佣金冻结逻辑
  @Transactional
  public void approveRefund(Long refundApplyId, BigDecimal refundAmount, String remark) {
      // ... 前置处理（省略）...
      
      // 冻结对应佣金（关键步骤）
      CommissionRecordDO commission = commissionRecordMapper
          .selectByReferredEnrollmentId(enrollment.getId());
      if (commission != null) {
          boolean canFreeze = CommissionStatusEnum.WAITING_FOR_CLASS.getStatus()
              .equals(commission.getCommissionStatus())
              || CommissionStatusEnum.PENDING_REVIEW.getStatus()
              .equals(commission.getCommissionStatus());
          if (canFreeze) {
              commissionRecordMapper.updateStatus(commission.getId(),
                  CommissionStatusEnum.FROZEN.getStatus());
              log.info("[refund] 佣金已冻结: commissionId={}, enrollmentId={}",
                  commission.getId(), enrollment.getId());
              // 通知推荐人
              applicationEventPublisher.publishEvent(
                  new CommissionFrozenEvent(commission.getReferrerMemberId(), commission.getId()));
          }
      }
  }
  ```

  > **说明**：开课 7 天后退费的场景（佣金已发放），退费不追溯已发放佣金，由退费流程独立处理。

## 4. 尾款催缴提醒（定时任务）

**文件**：`BalanceReminderJob.java`

```java
@JobHandler(value = "balanceReminderJob")
@Component
public class BalanceReminderJob implements IJobHandler {
    
    @Override
    public ReturnT<String> execute(String param) {
        // 每天 10:00 执行
        // 查询 status=DEPOSITED，且对应班期 start_date 在 7 天后的报名记录
        LocalDate reminderDate = LocalDate.now().plusDays(7);
        List<EnrollmentDO> enrollments = enrollmentMapper
            .selectDepositedWithSessionBefore(reminderDate);
        
        for (EnrollmentDO enrollment : enrollments) {
            // 发站内信 + 微信订阅消息：请在 XX 前完成尾款支付
            notifyService.sendBalanceReminder(enrollment);
        }
        return ReturnT.SUCCESS;
    }
}
```

- [ ] XXL-JOB 配置：
  - Cron：`0 0 10 * * ?`（每天10:00）
